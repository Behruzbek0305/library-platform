# Kutubxona – axborot resurs markazi (o'quv loyihasi)

Oddiy veb-sayt: HTML + CSS + JavaScript. Server va baza kerak emas, ma'lumotlar brauzerning `localStorage` xotirasida saqlanadi.

## Ishga tushirish

1. VS Code'da `kutubxona-sayt` papkasini oching (File → Open Folder).
2. `Live Server` kengaytmasini o'rnating.
3. `index.html` ustida o'ng tugma → **Open with Live Server**.

(Yoki `index.html` faylini brauzerda ikki marta bosib ochsangiz ham ishlaydi.)

## Sinash uchun admin

- Email: `admin@kutubxona.uz`
- Parol: `admin123`

## Papka tuzilmasi

```
kutubxona-sayt/
├── index.html      – sahifalar tuzilmasi
├── css/style.css   – dizayn
└── js/
    ├── data.js     – boshlang'ich kitoblar va resurslar
    └── app.js      – saytning barcha ishlash mantiqi
```

## Eslatma

Bu loyiha o'quv maqsadida yozilgan. Parollar brauzer xotirasida oddiy usulda saqlanadi, shuning uchun haqiqiy foydalanuvchilar uchun ishlatmang. Haqiqiy saytda Firebase kabi xavfsiz xizmat kerak bo'ladi.
